# traceipv4

Trace digests and ipv4 fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/traceipv4/

## Install / run

```bash
git clone https://github.com/theworker02/traceipv4.git
cd traceipv4
node src/cli.js
node --test
```
